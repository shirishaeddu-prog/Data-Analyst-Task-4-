Task 4: Dashboard Design

Objective
To create a simple sales dashboard using Python that helps understand sales, profit, and growth.

Tools Used
- Python
- Pydroid 3

Dataset
The project uses sample monthly sales and profit data.

Features
- Calculates Total Sales
- Calculates Total Profit
- Displays monthly Sales
- Displays monthly Profit
- Calculates Sales Growth

How to Run
1. Open the code in Pydroid 3.
2. Run the Python program.
3. The dashboard summary will be displayed in the output screen.

 Output
The program displays:
- Total Sales
- Total Profit
- Monthly Sales
- Monthly Profit
- Growth Percentage

 Conclusion
This project demonstrates a basic dashboard approach for analyzing sales data and supporting business decisions. Data-Analyst-Task-4-
